Medieval Clicker Game


Description:

A small and simple Android clicker game developed as a project during my Unity education. Immerse yourself in a cozy medieval world with bright colors and relaxing, meditative gameplay. Designed to be accessible and engaging, this game provides a calming experience with easy mechanics—click, enjoy, and watch your progress grow!

Features:

Bright, colorful medieval aesthetic

Relaxing and meditative gameplay loop

Easy to pick up, hard to put down

Open for future updates: new features, content, and improvements coming soon!


Technologies:

Unity Engine

C# scripting

Android build target


Future Plans:

The project is structured to support easy updates and additions. I plan to expand the game with new features, content, and polish to enhance the player experience.


Usage:

Download and run the APK file (Protector.rar archive) to install the game on your device. 


Contribution & Links:

If you share or reference this project anywhere, please include a link to this GitHub repository or my profile.
